# CityLife General Hospital – Patient Analytics Dashboard

## 📊 Project Overview

This project is a Power BI Patient Analytics Dashboard created for CityLife General Hospital.

The dashboard helps hospital management analyse patient information, insurance coverage, age groups, departments, and other patient-related data.

## 🎯 Business Problem

CityLife General Hospital needs a clear way to analyse patient data and understand patient demographics and insurance coverage.

The Power BI dashboard provides insights into:

- Total number of patients
- Insured and uninsured patients
- Patient age groups
- Department-wise patient information
- Patient demographics
- Insurance coverage analysis

## 📁 Dataset

**Dataset:** CS2_CityLife_Hospital
**Records:** 2,000 rows

### Main Columns

- Patient ID
- Patient Name
- Age
- Gender
- Department
- Insurance Status
- Admission Date
- Discharge Date
- Diagnosis
- Treatment
- City
- Other patient-related fields

## 🧹 Data Cleaning

The data was cleaned using Power Query.

The cleaning process included:

- Correcting data types
- Handling missing values
- Removing unnecessary spaces
- Standardising categorical values
- Checking for duplicate records
- Converting date columns to the correct date format

## 🧮 DAX Measures

The dashboard uses DAX measures to analyse patient data, including:

- Total Patients
- Insured Patients
- Uninsured Patients
- Patient counts by department
- Patient counts by age group
